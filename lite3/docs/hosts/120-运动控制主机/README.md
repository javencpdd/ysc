# 120 运动控制主机

本目录保存 `ysc-f20-120`（实际 hostname 为 `ysc`）的 Lite3 运动控制、视频、网络和部署审计材料。设备树标识为 Rockchip RK3588 WEB-S3588-YSC-V10，并通过 `192.168.1.0/24` 业务网与 103 感知导航主机协同。

## 专题目录

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| [`概览与账户/`](概览与账户/README.md) | `/home/ysc` 模块总览及 `user`/`ysc` 账户关系 | 首次了解运行目录或清理文件前阅读。 |
| [`运动控制与导航/`](运动控制与导航/README.md) | `jy_exe`、Lite3 SDK、导航接入边界及底层部署 | 维护机器人控制、策略、CAN、boot 制品前阅读。 |
| [`视频与流媒体/`](视频与流媒体/README.md) | RTSP、MediaMTX、RTMP 转发与视频发布 | 排查摄像头、流媒体服务或外部推流前阅读。 |
| [`网络与连接/`](网络与连接/README.md) | Wi-Fi 热点、NetworkManager、从机连接脚本 | 调整路由、热点、无线接口前阅读。 |
| [`依赖库与SDK/`](依赖库与SDK/README.md) | 离线依赖库与 SDK 边界 | 更新或清理依赖库前阅读。 |

## 使用方式

1. 日常状态先阅读“概览与账户”及上级跨主机维护说明；
2. 涉及运动、CAN、CPU/IRQ、热点、boot 分区或策略模型的操作必须在维护窗口执行；
3. 二进制、模型、SDK、密钥和厂商制品不构成修改或重新分发授权。
