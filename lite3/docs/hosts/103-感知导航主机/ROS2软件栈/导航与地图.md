# ROS 2：导航、定位与地图

## 目录定位与职责

- `nav/src/hdl_localization`：基于点云/IMU 的 NDT 定位组合节点。
- `nav/src/dr_nav2`：Nav2 集成和地图/RViz 配置。
- `slam/src/faster_lio`：Faster-LIO 集成；算法实现按第三方处理。
- `slam/src/pcd2grid`：调用 OctoMap 与 Nav2 map saver，从 PCD 生成/保存二维地图。

## 定位导航运行流程

`system/scripts/nav/start_nav.sh` 启动 `hdl_localization lite_localization.launch.py`：

```text
/rslidar_points、/imu/data
  -> hdl_localization_composition
      发布 /odom、/aligned_points、/status
  -> include dr_nav2.launch.py
      -> nav2_bringup + lite3.yaml + lite_nav2.yaml + RViz2
```

定位 launch 固定读取 `/home/ysc/lite_cog_ros2/system/map/lite3.pcd`；点云重映射 `/velodyne_points -> /rslidar_points`，IMU 重映射 `/gpsimu_driver/imu_data -> /imu/data`。关键设置为 `base_link`、IMU 启用、NDT_OMP、`DIRECT1`、NDT 分辨率 `1.5`、下采样 `0.5`、初始位姿原点、关闭全局重定位。

`dr_nav2.launch.py` 提供 `map_file` 与 `dr_nav2_config_file` 两个 launch 参数，默认分别为 `system/map/lite3.yaml` 和包内 `config/lite_nav2.yaml`；它 include `nav2_bringup/bringup_launch.py` 并启动 RViz2。

## 建图/栅格脚本

| 脚本 | 参数/交互 | 执行流程 |
| --- | --- | --- |
| `slam/start_slam.sh` | 无；要求图形桌面 | 新开 Faster-LIO、gridmap、save-map 三个终端。 |
| `slam/gridmap.sh` | 仅输入 `1` | source SLAM install，运行 `pcd2grid.launch.py`。 |
| `slam/save_map.sh` | 仅输入 `2` | 删除 `system/map/lite3.pgm/.yaml`，调用 `/map_saver_server/save_map` 保存 `/projected_map`。 |

`pcd2grid.launch.py` 启动 `octomap_server/my_octomap`，读取 `system/map/lite3.pcd`，重映射 `/cloud_in -> /pcd`，设置点云 Z 范围 `0.4..1.2`、栅格 Z 范围 `0..1.6`、分辨率 `0.05`；同时启动 `map_saver_server`、其 lifecycle manager 和 RViz2。

## 上下游依赖

- 上游：Leishen/其他雷达点云、IMU、Faster-LIO 或已有 PCD。
- 下游：`lite3.yaml` 由 Nav2 使用，`lite3.pcd` 由 hdl_localization 和 pcd2grid 使用。
- 外部依赖：`navigation2-foxy`、`fast_gicp`、`ndt_omp`、`octomap_mapping`、`grid_map_foxy` 是上游/第三方算法或库目录。

## 风险与硬编码

1. **保存前先删除**：ROS 2 `save_map.sh` 使用不带确认的 `rm` 删除现有 YAML/PGM；地图保存服务失败时会留下不完整地图。
2. **地图文件分裂**：save-map 产生 YAML/PGM，定位仍需要 PCD；更新流程缺少将新栅格与点云版本绑定的机制。
3. **双 RViz/GUI 依赖**：SLAM 启动器和 launch 可能各自启动 RViz；无图形环境不适合直接运行。
4. **硬编码安装位姿与传感器话题**：`base_link`、`rslidar`、IMU 话题、静态 TF 数值均与具体机型挂钩。
