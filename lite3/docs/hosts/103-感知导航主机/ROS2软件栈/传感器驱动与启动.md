# ROS 2：传感器驱动与系统启动

## 目录定位与职责

ROS 2 主工作区是 `/home/ysc/lite_cog_ros2`，运行时统一 source Foxy 与各工作区的 `install/setup.bash`。驱动目录 `driver/*` 及其 SDK/构建产物仅登记，不递归展开。

## 脚本清单

| 脚本 | 参数 | 执行流程与用途 |
| --- | --- | --- |
| `depth_camera/realsense/start_realsense.sh` | 无 | 设置 Cyclone DDS、Foxy、日志目录 `driver/realsense_ws/run_log`，source RealSense 工作区，后台 `ros2 launch realsense2_camera dr_camera_launch.py`。 |
| `lidar/start_livox.sh` | 无 | source `driver/mid360_ws/install/setup.bash`，前台运行 `livox_ros_driver2 msg_MID360s_launch.py`。 |
| `lidar/start_lslidar.sh` | 无 | source `driver/leishen_ws/install/setup.bash`，前台运行 `lslidar_driver lslidar_c16_launch.py`。 |
| `nav/start_nav.sh` | 无 | 依次 source `navigation2-foxy`、`nav`，运行 `hdl_localization lite_localization.launch.py`。 |
| `transfer/start_transfer.sh` | 无 | 设置 Foxy/Cyclone DDS/日志，source transfer，后台运行 `transfer transfer_launch.py`。 |
| `voa/start_voa.sh` | 无 | 设置 Foxy/Cyclone DDS/日志，source VOA，后台运行 `voa voa_launch.py`。 |

SLAM 的三个脚本见同目录的 `导航与地图.md`。

## 调用与启动场景

```text
RealSense / Livox / Leishen 驱动
  -> ROS 2 点云、IMU、图像
  -> hdl_localization 或 Faster-LIO
  -> Nav2、VOA、Transfer
```

ROS 2 当前由 `transfer_ros2.service` 自动运行。该服务只覆盖 transfer，不会自动启动雷达、相机、导航、SLAM 或 VOA；这些脚本是人工 bring-up 的入口。

## 关键配置与变量

- RealSense、transfer 与 VOA 显式设置 `RMW_IMPLEMENTATION=rmw_cyclonedds_cpp`。
- RealSense/VOA 分别将日志写入各自 `run_log`，transfer 写入 `system/log`。
- 系统环境由 `.ros_version.sh` 提供 `ROS_DOMAIN_ID=0`。

## 风险与硬编码

1. **硬编码 install 路径**：脚本要求已成功 colcon 构建；删除或迁移 `install` 后不会自动恢复。
2. **驱动并非互斥保护**：脚本没有检查另一款雷达/相机是否已占用设备或话题。
3. **后台启动无健康检查**：RealSense、transfer、VOA 以 `&` 启动，脚本结束不代表节点健康。
4. **DDS 一致性**：仅部分脚本显式设置 Cyclone DDS；从不同 shell 启动节点时需确认 RMW 一致，避免 DDS 发现/通信问题。
