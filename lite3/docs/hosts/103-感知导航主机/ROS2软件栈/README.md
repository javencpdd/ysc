# ROS 2 软件栈

本目录记录 103 主机 ROS 2/Foxy 工作区的传感器、定位导航、地图和安全控制集成。

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| [传感器驱动与启动.md](传感器驱动与启动.md) | RealSense、Livox、Leishen 与各启动脚本 | 启动传感器或排查 DDS 环境时阅读。 |
| [导航与地图.md](导航与地图.md) | HDL localization、Nav2、点云与栅格地图 | 运行定位、导航或保存地图前阅读。 |
