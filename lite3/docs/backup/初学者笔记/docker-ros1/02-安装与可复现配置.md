# 安装与可复现配置

## 1. 检查 Windows、WSL 和 Docker

在 **PowerShell** 中执行：

```powershell
winver
wsl --version
wsl --status
wsl -l -v

docker version
docker info
docker compose version
docker run --rm hello-world
```

WSL 发行版应使用 WSL2。更新或配置变更后可执行：

```powershell
wsl --update
wsl --shutdown
```

随后重新启动 Docker Desktop。

## 2. 首选方案：使用 ROS Docker 镜像

在 **PowerShell** 中拉取带桌面和仿真工具的 Noetic 镜像：

```powershell
docker pull osrf/ros:noetic-desktop-full
docker image inspect osrf/ros:noetic-desktop-full
```

记录镜像摘要，避免以后拉到不同内容：

```powershell
docker image inspect osrf/ros:noetic-desktop-full `
  --format '{{index .RepoDigests 0}}'
```

如需长期保留，可制作离线归档：

```powershell
docker save osrf/ros:noetic-desktop-full `
  -o ros-noetic-desktop-full.tar

docker load -i ros-noetic-desktop-full.tar
```

> 固定 digest、保存 Dockerfile 和备份镜像，比依赖未来仍能通过 `apt` 完整重建遗留环境更可靠。

## 3. 备用方案：在 Ubuntu 中安装 ROS

如果不使用预装 ROS 的镜像，而是在 Ubuntu 20.04、WSL Ubuntu 或自建基础镜像中安装，可优先按照 ROS 对应发行版的标准安装流程操作。

也可将鱼香 ROS 一键安装脚本作为**替代备用方案**：

```bash
cd ~ && wget http://fishros.com/install -O fishros && . fishros
```

注意：

- 该命令必须在 Ubuntu Bash 中运行，不是在 Windows PowerShell 中运行；
- 它会下载并立即执行远程脚本，运行前建议先查看脚本内容和来源；
- 交互时选择与 Ubuntu 20.04 匹配的 ROS 1 Noetic；
- 自动脚本适合快速搭建或标准源访问受限时备用，正式项目仍应记录具体软件源、包版本和安装步骤；
- 若容器已经基于 `osrf/ros:noetic-desktop-full`，无需再次安装 ROS。

安装后验证：

```bash
source /opt/ros/noetic/setup.bash
rosversion -d
which roscore
```

期望 `rosversion -d` 输出：

```text
noetic
```

## 4. 配置 VcXsrv

第一次使用 XLaunch 时可选择：

```text
Display settings: Multiple windows
Display number:   0
Client startup:   Start no client
Extra settings:   Clipboard、Native OpenGL/OpenGL
```

排错阶段可临时启用 `Disable access control`，但不要在不可信网络中长期这样运行。Windows 防火墙只应允许可信网络访问 VcXsrv。

## 5. 最小启动与分层验证

在 **PowerShell** 中：

```powershell
docker run --rm -it `
  --name ros1-noetic `
  -e DISPLAY=host.docker.internal:0.0 `
  -e QT_X11_NO_MITSHM=1 `
  --shm-size=1g `
  osrf/ros:noetic-desktop-full `
  bash
```

容器中安装诊断工具：

```bash
apt-get update
apt-get install -y \
  x11-apps mesa-utils netcat-openbsd \
  iproute2 iputils-ping usbutils
```

严格按以下顺序验证：

```bash
cat /etc/os-release
echo "$DISPLAY"
getent hosts host.docker.internal
xeyes
glxinfo -B
source /opt/ros/noetic/setup.bash
rosversion -d
roscore
```

另开一个 PowerShell 终端：

```powershell
docker exec -it ros1-noetic bash
```

在容器中运行：

```bash
rosrun turtlesim turtlesim_node
```

第三个终端进入相同容器并运行：

```bash
rosrun turtlesim turtle_teleop_key
```

若 `xeyes`、OpenGL 信息、ROS Master 和 turtlesim 都正常，基础链路已经打通。
