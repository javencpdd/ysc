# 文档目录

`docs/` 是本笔记库的文档入口。103 侧可运行源码、部署脚本和复现流程在并列的 `/home/jack/lite3Code` 仓库；本目录用于记录环境、审计依据、风险与方案。

## 文件与子目录

| 路径 | 内容 | 使用方式 |
| --- | --- | --- |
| [`codebase-map.md`](codebase-map.md) | `lite3Code` 与本库的模块映射、历史副本和更新规则 | 查找代码与笔记的对应关系时先读。 |
| [`hosts/`](hosts/README.md) | 103、120 两台主机的环境、脚本、模块和服务分析 | 需要定位某台主机的部署背景、依赖或风险时进入对应主机目录。 |
| [`operations/`](operations/README.md) | 两台主机的实测配置汇总、角色对比和维护注意事项 | 日常维护前优先阅读，核对当前状态和变更边界。 |
| [`scan-planner-note/`](scan-planner-note/README.md) | 规划器兼容性、部署与真机流程的阶段性记录 | 与 `lite3Code/scan_planner/scripts/` 一起核对后使用。 |
| [`project/`](project/Lite3%20火灾巡检系统%20v1.0%20工程实施计划.md) | 火灾巡检项目的计划与可行性评估 | 讨论方案或阶段目标时阅读，不作为已部署状态。 |
| [`backup/`](backup/初学者笔记/README.md) | 旧笔记、PDF 等归档资料 | 仅作历史参考。 |

## 使用约定

- 主机目录保存该主机的报告与索引；`hosts/103-home-test-docs/` 是 103 文档历史副本，不能代替 `lite3Code` 的当前文件。
- 跨主机结论写入 `operations/`；实现或部署配置的改动应先在 `lite3Code` 中核对。
- 文档中的服务状态、地址、端口和资源用量会随时间变化。引用时应保留报告中的采集时间，并在变更前重新实测。
- 新增一级目录时，必须新增同级 `README.md`，写明职责、文件清单与阅读方式。
