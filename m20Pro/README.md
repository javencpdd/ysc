## 核心结论速查

- **视频流**：前后广角相机 RTSP 拉流地址 `rtsp://10.21.31.103:8554/video1`（前）/ `video2`（后），由 GOS 提供（官方文档口径）。
  - 实测补充（2026-10-13，AOS `192.168.0.196` 现场）：本机 `~/rtmp_1012` 部署把相机流经本机 MediaMTX 在 `127.0.0.1:8554` 提供，并由 `rtmp_forward.sh` 转推外部 SRS `rtmp://172.31.68.227:1936/live/m20pro-f|b`（详情见 `analysis/01-RTSP与推流能力分析.md` 与本次会话的现场核查记录）。
- **计算平台**：三主机均为 RK3588（4×A76+4×A55，Mali-G610 MP4 GPU，16GB+128GB，Ubuntu 20.04 + kernel 5.10.198），无独显、无 NPU；`/dev/mpp_service` 硬编解码可用。
- **接入方式**：对外仅 AOS `192.168.0.196`（user / 密码 `'`）；NOS `10.21.31.106`、GOS `10.21.31.104` 仅内网，经 AOS 跳板（用 `m20ssh`）。
