# 03 · 三主机硬件巡检报告

> 2026-10-12 经 SSH 实测（AOS `192.168.0.196` 为唯一对外入口，NOS/GOS 经 AOS `sshpass` 跳板）。
> 全程只读巡检，未在机器人上写入任何持久化文件。

## 一、连接拓扑

```
开发机 ──SSH(user/')──> AOS 192.168.0.196 ──sshpass──> NOS 10.21.31.106
                                             └───────> GOS 10.21.31.104
```

- 局域网 192.168.0.0/24 扫描证实：对外只有 192.168.0.196 一个 SSH 暴露点；
- AOS 网卡：eth0 10.21.33.103 / eth1 10.21.32.103 / eth2 10.21.31.103 / wlan0 10.21.41.1（AP）/ p2p0 192.168.0.196（DHCP）/ docker0；
- AOS 的 OpenSSH 为 8.2p1（不吃 SSH_ASKPASS），故中转用 AOS 自带 `sshpass`；ProxyJump 在本环境 banner 超时，不可用。

## 三、AOS 磁盘分区（eMMC 115.3G）

| 分区 | 大小 | 挂载点 | 用途 |
|---|---|---|---|
| p3 | 256M | /boot | 启动 |
| p6 | 100M | /var/opt/robot/conf | 配置 |
| p7 | 7.8G | /var/opt/robot/log | 日志 |
| p9 | 7.8G | /opt/robot | 程序 |
| p10 | 7.8G | /var/opt/robot/record | 记录 |
| p11 | 62.5G | /var/opt/robot/data | 数据大盘 |
| p12 | 8.5G | /root-ro（只读层，已用 97%） | 系统只读层 |
| p13 | 18.4G | /userdata（overlay 可写层，已用 24%） | 实际写入落这里 |

## 四、运维注意点

1. **`/root-ro` 97% 是只读层固有占用**，实际可写空间看 `/userdata`（18G 用 4.3G，充裕）；OTA/更新报空间不足时优先清 `/var/opt/robot/log`。
2. **核隔离**：AOS 隔离 5 核、GOS 隔离 4 个 A76 大核给关键任务；跑实验负载用 `taskset` 避开隔离核，或直接用 NOS（无隔离）。
3. 跨主机操作必须经 AOS 跳板，用 `m20ssh`（见 `../scripts/`）。
4. AOS `/home/user/` 下发现非本次产生的文件：`v2/m20pro-f.png`、`v2/m20pro-b.png`、`rtmp_1012/m20video`（目录）——疑为既往视频试验产物，待用户确认处置。

## 五、复现方式

```bash
m20ssh --list
m20ssh aos  'bash -s' < ../scripts/lib/aos_hw.sh     # AOS 全量巡检
m20ssh nos  'bash -s' < ../scripts/lib/hw_all.sh     # NOS 精简巡检
m20ssh gos  'bash -s' < ../scripts/lib/hw_all.sh     # GOS 精简巡检
```
