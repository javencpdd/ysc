# ADR-015：控制台卡片折叠

- 状态：已采纳并部署（v0.8.3，2026-10-17）
- 相关：ADR-005（可视化控制台）、ADR-012（相机画面）、ADR-013（中英适配）、ADR-014（留存卡分节）

## 背景

控制台单页越做越长：状态指标 + 11 张卡片（采集开关 / 最近检测 / 相机画面 /
目标图片时间轴 / 数据文件 / 检测配置 / 相机与采集 / 关注目标 / 单帧检测 /
运行日志 / 日志与数据留存策略）。日常使用只需其中一两张（如"相机画面"或
"最近检测"），其余把页面撑得很长，滚动成本高。

更实际的代价是**后台轮询**：`setInterval` 每 3~5 秒为看不见的卡片发请求
（相机画面 3s、运行日志 4s、时间轴 15s、最近检测 5s），页面开着就一直在拉。

## 决策

**纯前端实现，零后端改动**（不新增接口、不改任何 API 契约）：

1. **每张卡片一个折叠按钮**：所有 `<div class="card">` 加 `data-fold="<key>"`
   属性；`initFolds()` 在 DOM 就绪后向 `h2` 注入一个 `.fold` 按钮（▾/▸），
   **不手写 11 处按钮**——避免以后新增卡片忘记加，也让 HTML 保持干净。
2. **折叠 = 隐藏 h2 之外的所有子元素**：
   `.card.collapsed > :not(h2){display:none}`。选这个写法而不是包一层
   `<div class="body">`，是因为**不必改动现有 DOM 结构**（11 张卡片的
   内容深浅不一，逐个包裹的风险远大于收益）。
3. **状态按卡记忆，与语言无关**：`localStorage["m20ai-fold-<key>"]`，
   key 用 `data-fold` 的固定英文标识，**不用标题文本**——否则中英切换后
   键就变了，记忆失效（`TestCardFold.test_js_hooks_present` 固化这一点）。
4. **顶栏「全部折叠 / 全部展开」**：一键切换全部卡片；按钮文案随当前状态
   在两种文案间切换（`syncFoldAllBtn()`），并同步本地化。
5. **折叠时暂停该卡的后台轮询**（本 ADR 的实际价值所在）：
   ```js
   setInterval(function(){ if (!document.hidden && !isFolded("snap") && el("snap-auto").checked) snapLoad(); }, 3000);
   setInterval(function(){ if (!isFolded("log") && el("auto-refresh").checked) loadLogs(); }, 4000);
   setInterval(function(){ if (!document.hidden && !isFolded("tl")) loadTimeline(); }, 15000);
   setInterval(function(){ loadStatus(); if (!isFolded("recent")) loadRecent(); }, 5000);
   ```
   注意 **`loadStatus()` 不判折叠**——顶部指标卡（帧数/告警/磁盘）不是可折叠
   卡片，始终刷新；被折叠卡片的**数据不丢**（后端一直在跑），展开时立即
   由下一轮（≤5 s）或用户手动刷新补齐。

## 实施

| 文件 | 改动 |
|---|---|
| `webconsole/static/index.html` | 11 张卡片加 `data-fold`；CSS `.card h2 .fold` / `.card.collapsed > :not(h2)` / `.card.collapsed{border-style:dashed}`；顶栏「全部折叠」按钮；JS `FOLD_KEY`/`foldId`/`isFolded`/`setFold`/`initFolds`/`toggleAllFolds`/`syncFoldAllBtn`；`applyI18n()` 末尾同步折叠按钮文案（语言切换后 ▾/▸ 的 title 与"全部折叠"按钮文字都跟着变）；4 个轮询加 `isFolded` 判断；新增 6 个双语键（`top.fold_all`/`_title`、`top.unfold_all`/`_title`、`card.fold`、`card.unfold`），词典 210 → **216 键** |
| `tests/test_webconsole.py` | 新增 `TestCardFold` 5 项：折叠键集合与唯一性（正则只扫 HTML 标签，避开 JS 里的选择器拼接）、CSS 钩子、JS 函数与记忆键、**轮询暂停断言**（逐条锁住 4 个定时器的 `isFolded` 条件）、折叠相关 i18n 键非空；另在 `TestI18nDict` 的死键白名单里登记 4 个动态引用键（`card.fold`/`card.unfold`/`top.unfold_all`/`top.unfold_all_title`） |

**有意不做**的：

- 不做"折叠详情卡（响应详情）"外的一键收起全部以外的高级记忆（如按分组折叠）——
  卡片不多，YAGNI。
- 不把折叠状态存到服务端——这是**每台浏览器**的显示偏好，不是机器人配置，
  存 localStorage 才是正确语义。

## 验证

- 单测：238 → **243 项全绿**（+5）。
- JS 语法：`node --check` 通过（提取内联 `<script>` 单独校验）。
- 真机（104，v0.8.3）：页面含 11 个 `data-fold`、`fold-all` 按钮、
  折叠 CSS；点击 ▾ 折叠/展开正常，刷新后状态保持；中英切换后按钮文案与
  title 同步；折叠「相机画面」后 `/api/snapshot` 请求停止（Network 面板确认），
  展开后 3 秒内恢复。

## 复审触发条件

- 卡片数量超过 ~20 张，或出现"分组浏览"需求 → 考虑侧边栏导航 + 锚点跳转，
  而非继续堆折叠。
- 若引入前端构建（打包/框架），折叠状态可提升为路由级的"页面布局记忆"。

## 修订记录 2026-10-17（v0.8.4）：修「折叠不彻底」并按"只留标题"收敛

**问题（用户实测反馈："我要的是整个卡片折叠，只留下卡片标题"）**：
v0.8.3 的折叠规则 `.card.collapsed > :not(h2)` **压不过行内样式**——卡片内的
图片元素由 JS 写 `img.style.display = "block"`（`snapLoad()` / `snapSourceDown()`），
行内优先级高于 class 选择器，**折叠后画面仍然显示**（"相机画面"最明显）。
另外「运行日志」这类 `h2` 里带工具条的卡片，折叠后仍是一长条控件。

**修复**：
1. 规则改为 `.card.collapsed > *:not(h2){display:none !important}`——`!important`
   可压过行内样式（行内未带 `!important` 时）；
2. 标题栏内同步收敛：`.card.collapsed h2 .row / .note {display:none !important}`，
   折叠态只保留**标题 + 状态徽标（`.tag`）**——"采集开关 已关闭"、"相机画面
   ⚠视频源不可达"这类状态一眼可见，而说明文字与按钮组（运行日志的级别过滤、
   时间轴的相机筛选）折叠时一并隐藏。

**真实浏览器验证（playwright-core，1440×1400，v0.8.4）**：
- 折叠「相机画面」：卡片高度 618 → **56 px**，`#snap-img` 计算样式 `display:none`、
  几何高度 0，全部子元素 `display:none`；
- **折叠后 3.2 s 内 `/api/snapshot` 请求数 = 0**（轮询确实停止）；
- 全部折叠：11 张卡片高度**统一 56 px**（`single` 卡本就隐藏为 0）；
- 刷新后 `localStorage.m20ai-fold-snap=1` 保持，按钮呈 ▸；
- 切 EN 后顶栏按钮变 "Expand all"（文案随语言同步）。
- 截图留档：`.playwright-cli/shots/01-all-expanded.png`、`03-all-collapsed.png`
  （截图目录已 gitignore）。

**新增回归测试**：`test_css_hides_body_when_collapsed` 同时断言两处 `!important`；
`test_inline_display_writers_are_known` 锁住"存在写行内 display 的 JS"这个前提
（若将来改为只在 JS 里判断折叠，该测试会提醒同步调整 CSS 策略）。244 项全绿。

## 修订记录 2026-10-17（v0.8.5）：修复「折叠后无法单独展开」

**问题（用户实测反馈）**：「检测配置 / 相机与采集 / 关注目标 / 日志与数据留存
策略」这 4 张卡用顶栏「全部折叠」收起后，**再也不能单独点开**（其余卡片正常）。

**根因**：这 4 张卡（外加默认隐藏的「单帧检测」）的标题写法与其它卡不同——
`data-i18n` **直接挂在 `<h2>` 上**（`<h2 data-i18n="cfg.title">检测配置</h2>`），
而 `applyI18n()` 对带 `data-i18n` 的元素执行**整块 `textContent` 重写**：
```js
document.querySelectorAll("[data-i18n]").forEach(function(e){ e.textContent = t(...); });
```
注入到 h2 里的 ▾ 折叠按钮是 h2 的**子节点**，于是被这次重写**整批清掉** ——
按钮没了自然点不开。其余卡片标题包在 `<span>` 里（`data-i18n` 在 span 上），
`h2.textContent` 未被触碰，所以不受影响。

**修复（两层）**：
1. **结构统一**：5 个 h2 的标题一律改为 `<h2><span data-i18n="...">标题</span></h2>`，
   与其它卡片一致（`TestCardFold.test_h2_never_carries_data_i18n` 固化：任何
   `<h2 data-i18n` 都会让测试失败）。
2. **幂等防御**：`applyI18n()` 末尾调用 `initFolds()` 重建清单（`initFolds` 已有
   `.fold` 则跳过，不会叠加），并统一按 class 状态重渲按钮符号与 title。
   这样即使将来又有人在 h2 上挂 `data-i18n`，下次语言渲染也会自动把按钮补回来
   （`test_apply_i18n_rebuilds_fold_buttons` 固化该防御必须存在）。

**真实浏览器验证（playwright-core，1440×1400，v0.8.5）**：
- 全展开态：11 张卡**全部**有 ▾ 按钮（修复前 5 张没有）；
- 「全部折叠」后**逐张点击**：**11/11 成功单独打开**，无一失败；
- 切到 EN：`total=11 / withBtn=11 / collapsed=11`（按钮未被语言渲染清掉）；
- 切回中文逐张展开：`reopened=11 / stillCollapsed=0`。

单测 244 → **246 项全绿**。
