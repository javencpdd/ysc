# ADR-005: 可视化控制台 m20-ai-console — 独立服务 + 零依赖 + 白名单提权

- 日期：2026-10-15
- 状态：已接受（已部署验证）
- 影响面：新增 `webconsole/`（后端 + 前端单页）、`deploy/m20-ai-console.{service,helper,sudoers,env.example}`、`deploy/console-bootstrap.sh`、`src/m20_ai_detect/`（results 保留天数）、README/USAGE、版本 0.3.0

## 背景

采样器（m20-ai-detect）交付后只有 CLI + env + systemd 三种交互方式，日常操作（开关服务、换检测接口、看日志、调留存）要 ssh 上 104 敲命令。用户要求可视化 Web UI：服务开关、检测接口选择（33 项能力）、检测方式（视频流抽帧 / 单帧上传）、运行日志查看、日志与数据留存策略编辑（时间/空间）。端口决策：**默认开放 5050**。

## 决策

1. **独立 systemd 服务 `m20-ai-console`，与采样器解耦**：控制台挂不影响采样，采样器挂不影响控制台；两者仅通过 env 文件与 systemctl 间接耦合。
2. **零第三方依赖（遵 ADR-002）**：后端 Python 标准库 `http.server`（ThreadingHTTPServer），前端原生 HTML/JS 单页（CSS 变量 + `prefers-color-scheme` 双主题）。GOS 上不用 pip 装任何包。
3. **提权收敛到唯一 root helper + sudoers 精确白名单**：
   - 读操作（`systemctl is-active`、`journalctl`）**不提权**——`user` 在 `adm` 组，journal 直接可读（2026-10-15 核实）；
   - 写操作（服务启停、journald/logrotate 配置）经 `/usr/local/sbin/m20-ai-console-helper`，sudoers 白名单**精确到完整命令行、无通配符自由参数**；
   - 参数经 req 文件（`tmp/console-<sub>.req`）传递，helper 内二次校验（纵深防御）；helper 动作记 syslog（`logger -t m20-ai-console-helper`）。
4. **5050 开放的安全边界**：绑定 0.0.0.0 = 机器人内网（10.21.31.x / 192.168.0.x）可达；AOS 无入站 DNAT，**外网到不了**。可选 token（`M20AIC_TOKEN`，默认空=内网开放；设置后 API 需 `X-Console-Token` 头）。
5. **配置与 CLI 同源**：UI 读写的就是 `m20-ai-detect.env` 本身（保留注释的就地改写 + 整份校验），不引入第二份配置；env 级改动重启采样器后生效，root 级立即生效。
6. **单帧检测是控制台侧能力**：直接调 AI 接口、即返即显（含结果图），不落库不进环形缓冲——与采样器的常驻视频流模式互补，不是它的替代。

## 依据

- 主机事实（2026-10-15 实测）：`user` 属 `adm` 组 → journalctl 免提权；`log/` 为空（服务日志走 journal）；journal 占 208M、logrotate daily×7、raw 环形 200MB 均已就位。
- `/api/v1/capabilities` 返回 33 项能力的 id/title/params，下拉列表实时拉取，失败不阻断页面。
- 白名单模型已验证：端到端重启采样器（API → sudo → helper → systemctl）成功，且 helper 的 `svc-*` 动词映射 bug 在部署验证中被抓出并修复（单测 mock 掉了 subprocess 层，端到端才暴露——已补端到端验证习惯）。

## 后果

### 正面

- 日常运维全流程浏览器完成，ssh 降为可选；
- 控制台崩溃/重启不影响采集；采集重启后控制台自动恢复显示；
- 提权面收敛到 6 条精确命令，审计可见（syslog + journal）。

### 负面 / 代价

- **多一个常驻服务**（256M 内存封顶、只用小核 0-3，与采样器同沙箱策略）；
- **内网开放意味着同网段任何人可控制服务**——缓解：可选 token；需要时 `M20AIC_BIND` 收紧到 10.21.31.104；
- 前端是手写单页，无构建无框架——迭代速度受限于手写 JS（可接受：功能面固定，不追求复杂交互）；
- `journald_limits` 改动会 `systemctl restart systemd-journald`（重启 journald 安全，但属系统级动作，已记 syslog）。

### 触发复审的条件

1. 需要多用户/权限分级 → 引入正式认证（session/token 升级）；
2. 控制台要暴露到公网 → 必须先有反代 + TLS + 强认证，禁止裸 5050 出公网；
3. 前端交互复杂化（实时帧预览等）→ 重估是否引入轻量框架（须同时修订 ADR-002）。
